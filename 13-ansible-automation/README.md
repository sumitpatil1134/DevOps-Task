# Task 13 - Ansible Configuration Management

## Objective

Learn server configuration automation using Ansible.

## What This Project Does

The Ansible playbook:

- Connects to a target host
- Installs Nginx
- Starts the Nginx service
- Enables Nginx
- Checks the Nginx service status
